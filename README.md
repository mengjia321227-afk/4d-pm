# 4D-PM 四维度项目管理系统

## 项目简介
个人项目管理工具，从海外、渠道、营销、HR四个维度统一管理项目进度和需求排期。

## 功能特性
- **四维度项目看板**：海外、渠道、营销、HR，每个维度独立管理
- **进度追踪**：实时显示项目完成百分比，自动识别延期状态
- **甘特图视图**：按周展示项目时间线
- **需求池管理**：记录、分类、优先级排序
- **需求挂接**：将需求关联到具体项目
- **需求排期**：为需求分配执行时间段
- **数据持久化**：所有数据存储在浏览器本地，刷新不丢失
- **数据导出**：支持导出JSON备份

## 使用说明

### 1. 查看项目
- 点击侧边栏的维度（海外/渠道/营销/HR）
- 查看该维度下的所有项目卡片
- 卡片显示：项目进度、状态、截止日期、关联需求数

### 2. 新建项目
- 点击「新建项目」按钮
- 填写项目名称、描述、起止时间、当前进度
- 系统自动计算状态（进行中/已完成/延期）

### 3. 查看甘特图
- 点击侧边栏的「XX甘特图」
- 按周查看项目时间分布
- 蓝色=进行中，绿色=已完成，红色=延期

### 4. 管理需求
- 点击「需求池」进入需求管理
- 新建需求：填写标题、描述、优先级、来源、期望完成时间
- 关联项目：点击需求行上的🔗按钮
- 排期：点击📅按钮安排执行时间
- 支持搜索和筛选

### 5. 数据备份
- 点击侧边栏底部的「导出数据」按钮
- 下载JSON备份文件
